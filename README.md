# catatdong. To-do List Kuliah

catatdong adalah website to-do list sederhana yang membantu mencatat tugas tugas kamu

# Fitur

- tambah tugas dengan mata kuliah dan deadline.
- taandai selesai, hapus tugas, atau undo penghapusan.
- filter tugas berdasarkan status dan lihat progres pengerjaan.
- mode terang/gelap.
- tugas tersimpan di browser setelah halaman dimuat ulang.

# Teknologi dan Tampilan

Website menggunakan HTML, plain CSS, dan JavaScript DOM, tanpa Bootstrap atau Tailwind. JavaScript digunakan untuk menambah, menghapus, menandai, dan memfilter tugas.

Tampilan responsif pada mobile, tablet, dan desktop. Pada mobile, form dan daftar tugas tersusun satu kolom. Pada tablet dan desktop, keduanya berdampingan.

# Cara Menjalankan

uka folder proyek di vscode, lalu klik kanan index.html lalu pilih *Open with Live Server*. bisa juga langsung membuka file tersebut di browser lewat link deployment.
